属性

新增页面 —— 要照抄哪一页？

新增＝把你在下面选的那一页复制一份插到末尾，版式（字号 / 有没有子项）跟它一样。
新增后会自动跳到新页面，双击左栏文字即可改成你自己的编号和名称。

怎么用

  1. 看所有页面 · 切页：左边一栏就是全部页面的缩略图（跟 PPT 左侧一样），点任意一张即切到该页；当前页绿色高亮。也可以用顶部「上一页 / 下一页」或底部圆按钮。
  2. 新增章节：点顶部「＋ 新增章节」→ 弹窗里点要照抄的那一页 → 新页面插到末尾，版式和它一样 → 双击左栏文字改编号和名称。
  3. 删除章节：点顶部「－ 删除本章节」删掉当前这一页（会先确认）。
    也可以：开「编辑模式」→ 鼠标移到左栏某条目上 → 点右侧出现的 × 直接删那一条。
  4. 加 / 删子项（1.1、2.1 这类）：点顶部「＋ 本章加子项」给当前页加； 要删当前子项页，点顶部「－ 删除子项」，会弹出确认；删除后同章其余子项会自动重新编号并上移 （例如 3.1 / 3.2 / 3.3 删掉 3.2，剩下的会变成 3.1 / 3.2）。
    也可以：开「编辑模式」后，鼠标移到左栏子项行上，点右侧出现的 × 删。
    子项就是单独一页：加了之后左侧缩略图会多出一张页，点左栏子项文字那一行即跳到它， 它有自己的正文。
  5. 位置自动排好：加 / 删子项后，下面所有章节会自动往下让位或上移，不会重叠，不用手动挪。 若你手动拖过某个条目把它钉住了，加子项时系统会自动解除钉住并重新排列（想保留手动位置请用「恢复自动排列」之外的方式微调）。
  6. 改文字：双击任何文字直接改（不用开编辑模式）。
  7. 编辑模式：点顶部「编辑模式」按钮开启。开启后左栏条目上才出现 ＋ / ×， 并且可以直接拖动章节条目 / 子项区 / 两个 logo / 两根白线 / 标语；点任意元素， 右下角面板可改位置 · 尺寸 · 颜色（改完自动保存）。 白底、三角等被盖住不好点的元素，用右下角面板顶部的「切换元素」下拉一点即选中。
    放映时这些 ＋ × 会自动消失，画面保持干净。
  8. 放映模式：点顶部「▶ 放映」进入全屏演示——工具条、缩略图全部隐藏，只留页面本身。
    键盘 ← →（或 空格 / PageUp / PageDown）翻页，Home / End 跳首尾，D 开关目录，F 全屏，Esc 退出； 鼠标不动时底部控制条会自动淡出，点画面也能翻下一页。
  9. 如果点了放映后浏览器边框还在（地址栏没消失），说明全屏请求被浏览器挡了——多半是因为当前在 预览窗口里。点控制条上的 ⧉ 浏览器打开，在新标签页里再点 ▶ 放映 或 ⛶ 全屏 即可。
  10. 悬浮目录：左下角「☰ 目录」按钮，展开后列出所有章节与子项，点任意一条直接跳到该页，当前页绿色高亮。放映时同样可用。
  11. 撤销 / 重做 / 保存：点「↶ 撤销」回到上一步（Ctrl+Z），点「↷ 重做」再往前一步（Ctrl+Y 或 Ctrl+Shift+Z） —— 增删改章节、子项、改文字、拖位置都能撤也能重做；按钮变灰表示没有更多历史。「💾 保存」立即存盘（Ctrl+S）， 其实每次改动都已自动保存到本机，点它只是图个安心。
  12. 左侧点到哪跳到哪：左栏章节和子项都单击即跳到那一页（点文字也跳，不用去戳空白）； 要改章节名 / 子项名就双击，文字变白底绿字即可编辑，回车保存、Esc 取消。
  13. 右侧内容不影响左栏：右边改大标题、改正文都只存在那一页里，不会改动左栏的章节名； 反过来，左栏章节名是唯一入口 —— 想改章节名就双击左栏。 （新页面还没自定义过标题时，右侧标题默认跟着左栏显示，一旦你自己改过右侧标题，它就独立了。）
  14. 放映时跳章节：放映中页面右下角有一排「跳到」圆点（鼠标动一下就出现），点哪个跳哪个； 也可以按 D 开目录。点这些地方不会误触发"翻下一页"。
  15. 所有改动自动存在本机浏览器（每页正文独立保存），刷新不丢；点「恢复默认」回到最初的 5 章、每章 1 个子项（共 10 页）。满意后点「导出 PDF」。

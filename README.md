# 三棵树导航式汇报模板（HTML 交互版）· v1.9.29

三棵树 / 马上住风格的 **16:9 网页汇报模板**：左侧绿色导航栏（含二级子项）、右上角 logo + 两行标语、PPT 式缩略图导航、全屏放映模式、悬浮目录（点标题跳页）、章节可增删改、选中态白底 + 绿三角、全元素可点选可拖动、localStorage 持久化。**单文件自包含**，离线即可导出 PDF / 可编辑 PPT，双击即开，可直接发给同事。

> 如果你手上是 `三棵树汇报模板-v1.5*.html`，那是已被淘汰的旧版（无 PPT 导出、未修复若干 bug），请换用本仓库的 **`三棵树汇报模板.html`**。

## 快速开始（只用 HTML）

1. 下载 `三棵树汇报模板.html`，用 Chrome / Edge / 360 双击打开。
2. 双击左栏改章节名、点正文写内容、点左侧 / 缩略图切页、`Ctrl+Z` 撤销 / `Ctrl+Y` 重做。
3. 导出：
   - **导出 PPT** → 生成 `.pptx`，图表可双击改数据、表格逐格改字、卡片/KPI/logo 都能点（原生对象，不是图片）。
   - **导出 PDF** → 生成 PDF。
4. 改完直接把 `.html` 发给同事即可（logo 已内联，不用带文件夹）。

## 装成 WorkBuddy 技能（给智能体用）

1. 把整个 `sks-nav-html-template` 文件夹复制到 `%USERPROFILE%\.workbuddy\skills\sks-nav-html-template`（Windows）。
2. 重启 WorkBuddy（或刷新技能列表）。
3. 对话里说「用三棵树模板生成一个汇报页」即可调用。

## 已知限制

- 放映 / 全屏在 WorkBuddy 内置预览面板（iframe）里会被拦截，请用文件里的「⧉ 浏览器打开」按钮或外部浏览器打开。
- 数据存浏览器 `localStorage`，换电脑 / 换浏览器不互通；迁移用「导出 PDF」或复制 `.html`。
- 从 v1.5.x 升级：若打开后布局错乱，清掉该站点 `localStorage`（删 `sks_tpl_v*` 相关 key）再刷新。
